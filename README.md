# TaskFlow

A task manager for Android built around your day. See what's due today, look ahead on a monthly calendar, and set tasks to repeat on whatever pattern suits you.

## Features
- Daily view.
- Monthly calendar.
- List view of upcoming tasks grouped by day.
- Search and filter by state.
- Recurring tasks: repeat on chosen weekdays or every N days, with an optional end date.
- Custom categories.
- Automatic rollover: unfinished one-time tasks from past days move to today, while completed one-time tasks and expired recurring tasks are cleared out
- Backup and restore to a JSON file or to Google Drive with optional automatic backup.
